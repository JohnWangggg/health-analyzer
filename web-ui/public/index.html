📘 如何从 iPhone 导出苹果健康数据？
  1. 打开 iPhone 上的 健康 App
  2. 点击右上角头像 → 导出健康数据 → 导出
  3. 选择"存储到文件"或"邮件"，得到一个 apple_health_export.zip
  4. 在本应用中上传即可（也可不上传 zip，提前手动解压缩后选择文件夹）
