建议添加到主屏幕

安装后可像普通 App 一样离线打开（数据仍只在本机处理）。

    1 上传健康数据

    推荐使用 iPhone「健康」App 导出的 ZIP。解析与统计均在本机完成。

    其他导入方式（XML / 文件夹）
    ⬆️

    点击选择文件

    支持 .zip / .xml

    可选：合并体脂秤 / 血压计 CSV

    支持欧姆龙类中文表头（含「测量日期时间」「体重」「体脂肪率」或「高压」「低压」）。 与苹果健康数据按时间合并，不覆盖已有记录；可在分析后补选再点下方按钮刷新。

    可选：限制分析日期范围

    不填则使用导出中的全部记录。

    可选：个人背景（写入提示词，仅本机保存）

    用药、目标体重与关注点会注入提示词；保存在本机 localStorage，不上传。

    隐私：健康明细默认不离开本机
    • ZIP/XML 不会上传到本站服务器；解析在浏览器内完成。
    • 完整分析结果默认只在当前页面内存；刷新后需重新上传。
    • 可选：个人背景写入 localStorage；摘要快照可写入 IndexedDB 供环比。
    如何从 iPhone 导出？
    1. 打开 健康 App → 右上角头像
    2. 导出健康数据 → 导出
    3. 存储到「文件」App，再在本页选择该 ZIP
    4. 体积很大时（数百 MB），建议在电脑浏览器打开本页再上传
