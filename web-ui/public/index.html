    点击选择文件

    支持 .zip / .xml

    可选：限制分析日期范围

    不填则使用导出中的全部记录。

    可选：个人背景（写入提示词，仅本机保存）

    用药、目标体重与关注点会注入提示词；保存在本机 localStorage，不上传。

    隐私：健康明细默认不离开本机
    • ZIP/XML 不会上传到本站服务器；解析在浏览器内完成。
    • 完整分析结果默认只在当前页面内存；刷新后需重新上传。
    • 可选：个人背景写入 localStorage；摘要快照可写入 IndexedDB 供环比。
    如何从 iPhone 导出？
    1. 打开 健康 App → 右上角头像
    2. 导出健康数据 → 导出
    3. 存储到「文件」App，再在本页选择该 ZIP
    4. 体积很大时（数百 MB），建议在电脑浏览器打开本页再上传

    使用建议
    • 国产模型对中文医学语境通常更贴切
    • 粘贴后可补充「请额外关注 XX」
    • 报告需与原始数据交叉核对，尤其是边界值

    隐私声明

    • 解析与统计在您的浏览器内完成，无后端上传健康明细
    • 完整分析默认只在当前页内存；刷新后需重新上传 ZIP/XML
    • 可选：个人背景 → localStorage；摘要快照 → IndexedDB（可清空）
    • PWA 缓存仅保存网页程序，不自动保存完整健康导出
    • 复制提示词后，是否发给第三方大模型由您决定
